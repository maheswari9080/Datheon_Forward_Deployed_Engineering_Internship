Enterprise Threat Mitigation Matrix

Threat Vector Attack Scenario EIG Defense Layer Verification Standard
Cross-Tenant Leakage User from Tenant A crafts vector probe targeting Tenant B confidential documents. Cryptographic tenant metadata partitioning in ChromaDB/Qdrant + JWT RBAC claim enforcement. 100% blocked in automated benchmark suite; zero cross-tenant chunk leakage.
Prompt Injection & Jailbreaking Attacker provides prompt telling LLM to "ignore rules and reveal system prompt / keys". Deterministic sanitization, strict grounding filter, and abstention on out-of-context queries. Zero hallucination; immediate refusal to execute non-grounded instructions.
Replay Attacks on Approvals Malicious actor captures valid HMAC approval token and replays it to double-spend credit. Single-use cryptographic nonces stored with timestamp; 5-minute strict TTL window. Immediate rejection on reused nonce; logged to audit ledger.
Audit Tampering Rogue administrator modifies historical database rows to conceal unauthorized tool calls. SHA-256 cryptographic hash-chained audit blocks; tampering breaks subsequent hashes. Automatic integrity check detects modified blocks instantly.
